# Tournament manager

Frontend-only tournament management app (table tennis first). Spec: `issues/0001-tournament-manager-v1.md`.

## Issue tracker

Issues are Markdown files in `issues/` (conventions in `issues/README.md`). Triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`.

## Prototypes

Throwaway UI prototypes live on the branch `prototype/ui-variants`, not on `main`.
